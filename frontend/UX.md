# Интерфейс: сценарий, словарь, экраны

Документ для согласования с командой. Экраны уже работают на моках в ветке `feature/frontend-ui`:
`cd frontend && npm ci && npm run dev`, затем http://localhost:5173.

## Сценарий пользователя

Пользователь — закупщик без технической подготовки.

1. **Загрузить.** Перетаскивает файл спецификации (xlsx, csv или pdf) на экран «Загрузка».
2. **Дождаться.** Видит полосу прогресса, счётчик позиций и оценку оставшегося времени. Страницу можно закрыть — задание останется в «Истории».
3. **Проверить.** Попадает в таблицу результатов: у каждой позиции код КТРУ и уверенность числом и цветом. Сначала смотрит позиции со статусом «Нужна проверка».
4. **Исправить.** Меняет неверный код: выбирает из предложенных кандидатов или ищет по каталогу. Верные коды принимает.
5. **Выгрузить.** Скачивает результат в xlsx или csv.

Шаги 1–3 готовы, шаги 4–5 — неделя 3 плана.

## Словарь интерфейса

Все надписи лежат в `src/texts.ts`. Эти слова используются везде одинаково.

| Термин | Что значит для пользователя | Значение в API |
| --- | --- | --- |
| Уверенность | Насколько система уверена в подобранном коде, от 0 до 100 % | `confidence` |
| Подобрано | Код подобран автоматически, уверенность высокая | `status: auto` |
| Нужна проверка | Система сомневается, код стоит посмотреть человеку | `status: needs_review` |
| Принято | Человек подтвердил код | `status: accepted` |
| Исправлено | Человек заменил код на другой | `status: corrected` |
| В обработке | Позиция ещё не обработана | `status: pending` |

Цвет уверенности: зелёный от 85 %, жёлтый от 60 до 84 %, красный ниже 60 %.
Пороги временные (`src/confidence.ts`), итоговые даст ИИ-инженер после калибровки.

Статусы задания: «В очереди» (`queued`), «Обрабатывается» (`processing`), «Готово» (`done`),
«Не удалось обработать» (`failed`).

## Экраны

| Экран | Адрес | Что видит пользователь | Главное действие |
| --- | --- | --- | --- |
| Загрузка | `/` | Поле для файла, форматы, лимиты (10 МБ, 1000 позиций), ссылка на файл-образец | Загрузить спецификацию |
| Ход обработки | `/jobs/:id` | Имя файла, полоса прогресса, «Обработано N из M», оставшееся время | Дождаться результата |
| Результаты | `/jobs/:id/results` | Сводка и таблица: строка, исходная строка, наименование, бренд, модель, код и наименование КТРУ, уверенность, статус | Проверить коды |
| История | `/history` | Список заданий: файл, дата, число позиций, статус | Открыть задание |

### Состояния, которые уже обработаны

- **Загрузка:** неподходящий формат, пустой файл, файл больше 10 МБ, отказ сервера, нет связи.
- **Ход обработки:** в очереди, обрабатывается, готово, задание упало, в файле нет позиций, задание не найдено, нет связи.
- **Результаты:** загрузка, нет позиций, задание ещё обрабатывается, задание упало, задание не найдено, нет связи.
- **История:** загрузка, пусто, нет связи.
